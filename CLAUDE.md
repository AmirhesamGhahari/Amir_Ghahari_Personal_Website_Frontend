## Project Overview
Personal portfolio website built with **Plasmic** (visual design tool) + **Next.js 14** (React framework). Plasmic generates the UI code; Next.js serves it. Output is a static site (plain HTML files) suitable for S3/Netlify hosting.

## Tech Stack
- **Next.js 14** with static export (`output: "export"` in next.config.mjs)
- **React 18** with TypeScript (`.tsx` files)
- **Plasmic** for visual design — synced via `npx plasmic sync`
- **Ant Design** component library (via `@plasmicpkgs/antd5`)

## Key Commands
```bash
npm run dev      # Local preview at http://localhost:3000
npm run build    # Generates static HTML into out/
npx plasmic sync # Pull latest design changes from Plasmic studio
```

## Folder Structure

| Path | Purpose |
|---|---|
| `pages/` | One file per URL route (index.tsx = home page `/`) |
| `components/*.tsx` | Your editable component wrappers — add behavior here |
| `components/plasmic/` | Auto-generated by Plasmic — NEVER edit manually |
| `styles/globals.css` | Site-wide CSS overrides |
| `out/` | Built static HTML — deploy this folder |
| `plasmic-init.ts` | Plasmic project credentials (ID + token) |
| `public/` | Static assets (favicon, images) |
| `node_modules/` | Downloaded libraries — never edit |

## The Golden Rule
**Plasmic owns the look, you own the behavior.**
- Design changes → Plasmic studio → `npx plasmic sync`
- Logic/data/interactivity → edit files in `pages/` and top-level `components/`
